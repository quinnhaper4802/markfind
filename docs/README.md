# markfind documentation

markfind indexes the text of the pages you've bookmarked, so you can search
your bookmarks by what the pages *say*, not just their titles.

- **[Getting started](getting-started.md)**: install, export your bookmarks,
  and run your first search in five minutes.
- **[Command reference](cli.md)**: every command and option, the search
  query syntax, and exit codes.
- **[How it works](how-it-works.md)**: importing, fetching, text extraction,
  the index and ranking, and the database schema.
- **[Python API](python-api.md)**: use markfind from your own scripts.
- **[Development](development.md)**: run the tests, the linters and CI, and
  make changes safely (including database migrations).

Runnable examples live in [`examples/`](../examples/README.md).
